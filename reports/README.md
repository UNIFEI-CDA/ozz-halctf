# Reports — OZZ + RAPTOR Security Analysis

This directory contains automated security analysis reports generated by the **OZZ + RAPTOR** pipeline.

## Pipeline

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│   RAPTOR     │────▶│   OZZ        │────▶│  RELATÓRIO   │
│  Semgrep     │     │  Exploits    │     │  Unificado   │
│  Static      │     │  Active      │     │  JSON+HTML   │
└──────────────┘     └──────────────┘     └──────────────┘
```

- **RAPTOR**: Static analysis with Semgrep (OWASP Top 10 + Security Audit rules)
- **OZZ**: Attack technique extraction from agent code + attack chain analysis
- **Correlation**: Cross-references RAPTOR findings with OZZ attack techniques
